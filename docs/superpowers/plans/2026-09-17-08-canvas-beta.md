# Flows canvas beta (n8n-like) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a **Beta** Flows tab where the user graphs agents, text, filters, and HTTP/MCP nodes: when one node finishes, its output feeds the next.

**Architecture:** New view + Zustand store, persisted under `.flashwork/history/flows/`. Agent nodes reuse Task Board spawn (`submitBoardTask` / prompt-run). Do not import the n8n codebase. Keep `AgentCanvasPOC` as the live-session inspector.

**Tech Stack:** React, `@dnd-kit/core` (already in the POC), SVG edges, Vitest for the runner.

**ADR:** `.claude/adr/007-canvas-beta-n8n.md`  
**Depends on:** P01 (tool selection), P02 (install), P04 (project folder), P07 (routing)

Paths relative to `apps/orchestrator/`.

### Task 1: Pure runner

- [ ] **Step 1: Failing tests**

```ts
it('pipes agent output into text then filter', async () => {
  const graph = {
    nodes: [
      { id: 'a', type: 'agent', data: { prompt: 'hi' } },
      { id: 't', type: 'text', data: { template: 'OUT: {{input}}' } },
      { id: 'f', type: 'filter', data: { includes: 'OUT:' } },
    ],
    edges: [
      { id: 'e1', from: 'a', to: 't' },
      { id: 'e2', from: 't', to: 'f' },
    ],
  }
  const result = await runFlow(graph, {
    runAgent: async () => 'hello',
    http: async () => { throw new Error('http should not run') },
    mcp: async () => { throw new Error('mcp should not run') },
  })
  expect(result.nodeOutputs.f).toBe('OUT: hello')
})

it('rejects cycles', async () => {
  await expect(
    runFlow(
      {
        nodes: [
          { id: 'a', type: 'text', data: { template: 'x' } },
          { id: 'b', type: 'text', data: { template: 'y' } },
        ],
        edges: [
          { id: 'e1', from: 'a', to: 'b' },
          { id: 'e2', from: 'b', to: 'a' },
        ],
      },
      idleDeps,
    ),
  ).rejects.toThrow(/cycle/)
})
```
