# Per-project harness and RAG — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Creating a project requires a destination folder; Flashwork writes `.flashwork/` with harness, RAG, and history isolated from other projects.

**Architecture:** Tauri command `project_bootstrap(folder, projectId)` creates the directory tree atomically. `NewProjectModal` blocks without a folder. Registry in profile `projects.json` stores `defaultCwd` as that folder. RAG = Graphify ensure + project context hub directory. Reuse `graphify_ensure_graph` and the 2026-09-04 hub spec.

**Tech Stack:** Rust (fs, serde), React modal, Vitest + cargo test.

**ADR:** `.claude/adr/005-per-project-harness-rag.md`  
**Related spec:** `apps/orchestrator/docs/superpowers/specs/2026-09-04-project-scoped-context-hub-design.md`

Paths relative to `apps/orchestrator/`.

### Task 1: Path helpers and bootstrap (Rust)

- [ ] **Step 1: Failing test `bootstrap_creates_flashwork_tree`** using `tempfile::tempdir`

```rust
#[test]
fn bootstrap_creates_flashwork_tree() {
    let dir = tempfile::tempdir().unwrap();
    let folder = dir.path().to_string_lossy().to_string();
    let home = crate::project_home::bootstrap(&folder, "proj_test").unwrap();
    assert!(home.join("project.json").is_file());
    assert!(home.join("harness").is_dir());
    assert!(home.join("rag").is_dir());
    assert!(home.join("history/tasks").is_dir());
}

#[test]
fn bootstrap_refuses_when_foreign_project_id_exists() {
    let dir = tempfile::tempdir().unwrap();
    let folder = dir.path().to_string_lossy().to_string();
    crate::project_home::bootstrap(&folder, "aaa").unwrap();
    let err = crate::project_home::bootstrap(&folder, "bbb").unwrap_err();
    assert!(err.contains("flashwork_exists"));
}

#[test]
fn bootstrap_is_idempotent_for_same_id() {
    let dir = tempfile::tempdir().unwrap();
    let folder = dir.path().to_string_lossy().to_string();
    crate::project_home::bootstrap(&folder, "aaa").unwrap();
    crate::project_home::bootstrap(&folder, "aaa").unwrap();
}
```
