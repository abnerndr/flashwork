# Flashwork orchestrator

Desktop app for this repo (`apps/orchestrator`): **Tauri 2 + React + Rust**.

Flashwork branding. Derived from [Flashwork Agents](https://github.com/abnerndr/flashwork-agents) under **AGPL-3.0-or-later**. See `NOTICE`, `LICENSE`, `TRADEMARK.md` (Flashwork name/logo are not used in the Flashwork UI).

## Run

From the **repository root** (not this folder):

See `../../docs/run-flashwork.md` and `../../scripts/`.

```bash
# Linux / WSL / macOS
../../scripts/dev.sh

# Windows
..\..\scripts\dev.ps1
```

Or: `npm run app` in this directory (Tauri dev overlay).
